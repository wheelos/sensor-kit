# Agent Resources

Repository agent resources are organized by purpose:

- `skills/`: reusable workflows with clear scope.
- `knowledge/`: verified, stable facts that are useful for future work.
- `notes/`: temporary investigation or migration context. Move validated
  conclusions to `docs/` or `knowledge/`, then remove obsolete notes.

See the repository-root [`AGENTS.md`](../AGENTS.md) for general agent entry
points and code-change rules. The authoritative project documentation is in
[`docs/`](../docs/README.md).
